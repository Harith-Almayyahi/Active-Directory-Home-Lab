# Active Directory Home Lab

## Overview

This project demonstrates a Windows Server 2022 Active Directory home lab built using VMware Workstation.

The lab was created to practice common IT Help Desk and System Administration tasks in a real Windows Server environment.

---

## Lab Environment

- VMware Workstation
- Windows Server 2022
- Active Directory Domain Services (AD DS)
- DNS Server
- Windows Client
- Active Directory Users and Computers

---

## Skills Demonstrated

- Installed Windows Server 2022
- Configured Active Directory Domain Services
- Created a new domain (harith.local)
- Configured DNS
- Created Organizational Units (OUs)
- Created user accounts
- Created security groups
- Added users to security groups
- Organized users by department
